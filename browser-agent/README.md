# Ozon Seller: браузерный контроль платных услуг (только чтение)

СТАТУС: код подготовлен и опубликован в репозитории. Не включён автоматически: владелец должен войти в Ozon в отдельном профиле Chrome, сохранить реальные адреса разделов и настроить Telegram. Никакие секреты в GitHub не передавать.

## Что проверяет

Существующий Vercel Cron уже проверяет доступные Seller API начисления, Premium и обычные акции. Этот дополнительный агент в Chrome читает личные страницы, которые не покрывает Seller API:
- Товары → Отзывы → Сбор первых отзывов (в некоторых версиях Товары → Сбор первых отзывов);
- Уведомления/лента уведомлений;
- Новости продвижения;
- Продвижение → Рекламные кампании;
- Платные услуги и подписки, если раздел существует.

Ozon меняет расположение страниц. Агент не угадывает URL: они записываются один раз в открытом кабинете. Если страница недоступна, это ОШИБКА, а не «услуг нет». Первый запуск создаёт исходную базу и показывает критичные признаки активных платных инструментов, не утверждая, что их подключили вчера. Далее новые признаки сравниваются с последней успешной проверкой.

Важно: открытие кнопки уведомлений может пометить уведомления просмотренными. При настройке требуется отдельное согласие на открытие колокольчика.

## Установка на Windows (Google Chrome и Node.js 22+)

1. Откройте https://github.com/shumka55omsk-lang/Ozon-Analyzer-v2- → Code → Download ZIP, распакуйте репозиторий.
2. Откройте папку browser-agent и запустите install.cmd.
3. В открывшемся ОТДЕЛЬНОМ Chrome войдите в Ozon Seller самостоятельно, включая подтверждение входа через телефон. НЕ пересылайте SMS-коды, пароли или cookies.
4. По запросам программы откройте каждый из пяти разделов и нажмите Enter в окне программы. Сохраняется URL в локальном профиле. Если раздел найти невозможно, нажмите s — это будет отмечено как неполная проверка.
5. Откройте приватный файл %LOCALAPPDATA%\OzonSellerAudit\.env.local, внесите три строки:

    TELEGRAM_BOT_TOKEN=значение_из_защищённых_настроек
    TELEGRAM_CHAT_ID=значение_из_защищённых_настроек
    OZON_HEADLESS=1

   Значения для Telegram-бота вашего проекта есть в защищённых настройках Vercel, но этот локальный процесс их автоматически не получает. Вставляйте секреты только непосредственно на своём компьютере, не в чат.
6. Запустите check-now.cmd и убедитесь, что отчёт пришёл в Telegram.
7. В папке browser-agent запустите PowerShell и выполните команду:

    powershell -ExecutionPolicy Bypass -File .\schedule.ps1

Задача OzonSellerBrowserAudit выполняется ежедневно в 08:30 **ПО ЛОКАЛЬНОМУ ВРЕМЕНИ КОМПЬЮТЕРА**. Если это не Омск, настройте время в schedule.ps1 с учётом вашего часового пояса. Компьютер должен быть включён и иметь доступ к интернету. Для независимой работы нужен отдельный постоянно работающий компьютер или сервер с отдельным авторизованным профилем.

## Безопасность и ограничения

- Никакие цены, акции, реклама и товары не изменяются.
- Программа не нажимает кнопки Подключить, Отключить, Сохранить, Запустить.
- Данные авторизации Chrome остаются только в %LOCALAPPDATA%\OzonSellerAudit\chrome-profile.
- Настройки и история остаются только в %LOCALAPPDATA%\OzonSellerAudit\data.
- Токен Telegram остаётся в локальном .env.local. Не добавляйте эти каталоги и файлы в Git.
- Агент не может знать, соглашался ли владелец на услугу. Активный статус — повод проверить вручную.
- Нельзя гарантировать, что любой интерфейс Ozon будет доступен автоматизации: может появиться CAPTCHA, новый layout или запрос новой авторизации. Агент обязан сообщить об ошибке, а не показать фиктивное «всё чисто».
- Если Telegram не настроен, локальный запуск завершится ошибкой. Для обнаружения полного отключения самого ПК нужен внешний контроль heartbeat (пока не установлен).

## Тесты

Из папки browser-agent запустите npm test. Это локальные тесты правил обнаружения, а не проверка вашего реального Ozon Seller.
