OZON COMPETITOR ANALYZER v2

Что нового:
- кнопка «Загрузить из Ozon»;
- серверная функция /api/ozon-product;
- автоопределение названия и цены;
- попытка определить вес и габариты;
- категория, продавец и рейтинг (если доступны);
- запасной разбор HTML/JSON-LD;
- ручной расчёт продолжает работать, даже если Ozon блокирует запрос.

Развёртывание на Vercel:
1. Распакуйте архив в репозиторий.
2. Загрузите файлы index.html, package.json и папку api.
3. Deploy. vercel.json не требуется.
4. Откройте сайт, вставьте полную ссылку вида https://www.ozon.ru/product/...-123456789/ и нажмите «Загрузить из Ozon».

Важно:
Внутренний API карточек Ozon не является официальным публичным API и может меняться или блокировать серверные запросы. Поэтому предусмотрен ручной режим.
