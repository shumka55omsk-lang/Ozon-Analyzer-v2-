Ozon Competitor Analyzer v4

Главное изменение: автозагрузка по ссылке больше не зависит от прямого запроса Vercel -> Ozon.
Ozon блокирует многие серверные IP антиботом, поэтому надёжный режим работает через обычный Chrome пользователя.

Установка:
1. Разверните содержимое этой папки на Vercel как раньше.
2. Распакуйте ozon-browser-import-extension.zip.
3. Откройте chrome://extensions
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение».
6. Выберите распакованную папку extension.
7. Обновите страницу калькулятора. В блоке товара должно появиться «расширение установлено».

Работа:
- вставьте полную ссылку товара Ozon;
- нажмите «Загрузить из Ozon»;
- расширение откроет карточку в фоновой вкладке, дождётся загрузки, считает открытые данные и закроет вкладку;
- найденные значения будут подставлены в калькулятор.

Если вес или габариты не представлены в загруженной части карточки, они останутся ручными — цена и название при этом загрузятся.
