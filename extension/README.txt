Установка расширения Chrome

1. Распакуйте папку extension в отдельное место на компьютере.
2. Откройте в Chrome: chrome://extensions
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите эту папку extension.
6. Вернитесь в калькулятор и обновите страницу.

После установки кнопка «Загрузить из Ozon» работает через обычный браузер:
калькулятор откроет карточку Ozon в фоновой вкладке, считает данные и закроет вкладку.

Версия 1.1.0: раздельное чтение подписанных цен с банками-партнёрами и с другими банками.
Для обновления распакуйте новый архив, замените файлы в установленной папке extension,
нажмите кнопку обновления расширения в chrome://extensions и обновите Analyzer.
Ожидаемая проверка на карточке 5459795463: при видимых 255 / 280 ₽ должны вернуться
именно эти две цены; 255 ₽ — в поле основной цены. Числа не зашиты в расширение.
Если подпись банковской цены не распознана, выводится предупреждение.
Разовая загрузка не включает мониторинг и не меняет цены продавца.
